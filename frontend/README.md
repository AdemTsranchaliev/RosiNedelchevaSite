# Frontend — Росица Неделчева

Next.js сайт за терапевтичните карти „Справяне с тревожността“.

## Страници

- `/` — продукт / начална
- `/za-men` — за Росица
- `/kontakti` — контакти
- `/blog` и `/blog/[slug]` — блог

## Стартиране

```bash
npm run dev
```

Отвори [http://localhost:3000](http://localhost:3000).

Съдържанието е в `src/lib/content.ts`. Снимките са в `public/images/`.
